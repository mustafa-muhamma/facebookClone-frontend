# Facebook-clone-frontend

This is a frontend web application built with **React.js** and **Context API** for state management.  
The app is designed with clean and well-structured code, following best practices for maintainability and scalability.  

## 🚀 Features
- **React Context API** – efficient global state management.
- **Axios** – for handling API requests and managing responses.
- **Environment Variables (.env)** – API endpoints stored securely.
- **Reusable Components** – modular and clean code organization.
- **Scalable Structure** – follows a professional folder structure.

## ⚠️ Note
This app depends on a backend service that I currently don’t have access to,  
so it cannot run out of the box.  
However, the frontend code is fully available for review, demonstrating API integration,  
state management, and secure practices.
